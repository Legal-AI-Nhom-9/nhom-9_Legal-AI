## Cấu trúc tệp nộp (zip)

```
Readme.md
source_code/      ← toàn bộ trang: index.html, imgs/, video/
docs/             ← kich-ban-video.md, thu-vien-cau-lenh.md, bang-xac-minh.md,
                    chinh-sach-ai.md, tao-video/make_video.py
```

Trong kho GitHub, trang nằm ở thư mục gốc (để GitHub Pages chạy); khi đóng zip, chép `index.html`, `imgs/`, `video/` vào `source_code/`.

## Sửa nội dung trang

Thêm `#sua` vào cuối địa chỉ trang (hoặc mở `index.html` trên máy) → nút **✏️ Chỉnh sửa trang** → sửa chữ → **Tải index.html** → tải tệp đó lên GitHub đè tệp cũ.
